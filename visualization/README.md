# 🎨 FuseLinker Visualization Tools

Comprehensive visualization suite for analyzing FuseLinker knowledge graph embeddings, graph structure, and model performance.

## 📋 Features

- **Embedding Visualization**: t-SNE and PCA plots for entity and relation embeddings
- **Fusion Analysis**: Compare text, domain, and learned embedding components
- **Graph Structure**: Visualize relation distribution, entity degrees, and graph topology
- **Interactive Dashboard**: Streamlit-based web interface for exploration

---

## 🚀 Quick Start

### 1. Train a Model (exports visualization data automatically)

```bash
cd ~/fussion-and-verify-in-BKG/fuselinker-complex

python main.py --data suppkg \
    --text_embedding_file ~/fussion-and-verify-in-BKG/engine/llama2_pretrained_embeddings_4096.npy \
    --knowledge_embedding_file ~/fussion-and-verify-in-BKG/engine/poincare_embeddings.npy \
    --num_hidden_layers 2 --n_hidden 200 --iterations 39166 \
    --w 0.75 --use_cuda True --use_n3_reg --use_reciprocal
```

✓ Visualization data automatically exported to `suppkg/visualization_outputs/`

### 2. Generate Static Visualizations

```bash
# Visualize embeddings (t-SNE and PCA)
python -m visualization.embedding_visualizer \
    --viz_dir suppkg/visualization_outputs \
    --output_dir suppkg/visualization_plots \
    --method both \
    --sample_size 1000

# Visualize graph structure
python -m visualization.graph_visualizer \
    --viz_dir suppkg/visualization_outputs \
    --output_dir suppkg/visualization_plots \
    --sample_nodes 50 \
    --sample_edges 100
```

✓ Plots saved to `suppkg/visualization_plots/`

### 3. Launch Interactive Dashboard

```bash
# Install requirements (if not already installed)
pip install streamlit plotly

# Launch dashboard
streamlit run visualization/app.py
```

✓ Dashboard opens at `http://localhost:8501`

## 🔧 Command-Line Options

### embedding_visualizer.py

```bash
python -m visualization.embedding_visualizer [OPTIONS]

Options:
  --viz_dir PATH          Directory with exported data (default: suppkg/visualization_outputs)
  --output_dir PATH       Directory to save plots (default: suppkg/visualization_plots)
  --method CHOICE         tsne, pca, or both (default: both)
  --sample_size N         Number of points to sample (default: 1000)
```

### graph_visualizer.py

```bash
python -m visualization.graph_visualizer [OPTIONS]

Options:
  --viz_dir PATH          Directory with exported data (default: suppkg/visualization_outputs)
  --output_dir PATH       Directory to save plots (default: suppkg/visualization_plots)
  --sample_nodes N        Nodes in graph sample (default: 50)
  --sample_edges N        Edges to sample (default: 100)
```

### app.py (Dashboard)

```bash
streamlit run visualization/app.py

# Dashboard configuration via sidebar:
# - Visualization Data Directory: suppkg/visualization_outputs
# - Embedding type: Entity/Relation/Text/Domain/Learned
# - Method: PCA or t-SNE
# - Sample size: 100-2000
```


### Example 2: Analyze Fusion Components


## 🎯 Interpreting Visualizations

### Entity Embeddings (t-SNE/PCA)

**What to look for:**
- **Clusters**: Entities with similar roles/properties group together
  - Example: All drug entities may cluster separately from disease entities
- **Outliers**: Unusual entities far from others
  - May indicate rare or unique entities
- **Separation**: Clear boundaries between different entity types
  - Indicates good discriminative embeddings

### Relation Embeddings

**What to look for:**
- **Relation similarity**: Similar relations (e.g., TREATS, CURES) should be close
- **Inverse relations**: With `--use_reciprocal`, REL and REL_INV should be distinct but related

### Fusion Component Comparison

**What to look for:**
- **Text embeddings**: Capture semantic similarity based on entity names/descriptions
- **Domain embeddings**: Capture hierarchical/structural knowledge
- **Fused embeddings**: Should combine strengths of both
- **Norm comparison**: Shows relative contribution of each component

### Relation Distribution

**What to look for:**
- **Balanced**: No single relation dominates (good for learning)
- **Skewed**: Some relations much more frequent (may need balanced sampling)
- **Reciprocals**: With `--use_reciprocal`, each relation should have ~equal forward/inverse counts

### Entity Degree Distribution

**What to look for:**
- **Power-law**: Few high-degree hubs, many low-degree nodes (typical for KGs)
- **Uniform**: All entities have similar degrees (rare, but possible for synthetic graphs)
- **Outliers**: Very high-degree entities are important hubs

## 🛠️ Troubleshooting

### Error: "No module named 'streamlit'"

```bash
pip install streamlit plotly
```

### Error: "Directory not found"

Make sure you've trained a model first - visualization data is exported automatically during training.

### Plots look crowded

Reduce sample size:
```bash
python -m visualization.embedding_visualizer --sample_size 500
python -m visualization.graph_visualizer --sample_nodes 30 --sample_edges 50
```

### t-SNE takes too long

Use PCA instead (much faster):
```bash
python -m visualization.embedding_visualizer --method pca
```

Or reduce sample size:
```bash
python -m visualization.embedding_visualizer --method tsne --sample_size 500
```

### Out of memory

Reduce sample sizes or process in batches.

## 📚 Technical Details

### Dimensionality Reduction Methods

**PCA (Principal Component Analysis)**
- ✅ Fast, deterministic, linear
- ✅ Shows global structure
- ❌ May miss local patterns
- Use for: Quick overview, variance analysis

**t-SNE (t-Distributed Stochastic Neighbor Embedding)**
- ✅ Preserves local structure
- ✅ Reveals clusters
- ❌ Slow, non-deterministic
- Use for: Detailed cluster analysis

### Data Export Process

1. **During Training**: `main.py` calls `export_full_visualization_data()` after evaluation
2. **Extraction**: Model embeddings, graph structure, and statistics exported
3. **Storage**: Saved to `<data_dir>/visualization_outputs/`
4. **Visualization**: Scripts load and process exported data

### Performance Tips

- Use `--sample_size 500` for faster t-SNE
- Use `--method pca` for instant results
- Dashboard: Start with PCA, switch to t-SNE for detailed views
- For large graphs (>10K entities): Sample aggressively or use PCA only
